## Malware threats


| ID   | Threat       | Meaning                                                           |
| ---- | ------------ | ----------------------------------------------------------------- |
| C001 | Virus        | Malicious code that infects files or programs.                    |
| C002 | Worm         | Malware that spreads between systems or devices.                  |
| C003 | Trojan Horse | Malicious software disguised as legitimate software.              |
| C004 | Ransomware   | Malware that locks or encrypts data to demand payment.            |
| C005 | Spyware      | Software that secretly monitors activity or collects information. |

## Social engineering threats

| ID   | Threat         | Meaning                                                            |
| ---- | -------------- | ------------------------------------------------------------------ |
| C006 | Phishing       | Deceptive messages intended to obtain sensitive information.       |
| C007 | Spear Phishing | Targeted phishing directed at a particular person or organization. |
| C008 | Smishing       | Phishing conducted through SMS messages.                           |
| C009 | Vishing        | Fraudulent attempts to obtain information through voice calls.     |
| C010 | Pretexting     | Using a fabricated situation or identity to manipulate someone.    |

## Network and service threats

| ID   | Threat                               | Meaning                                                             |
| ---- | ------------------------------------ | ------------------------------------------------------------------- |
| C011 | Denial of Service (DoS)              | Disrupting a service so legitimate users cannot access it.          |
| C012 | Distributed Denial of Service (DDoS) | Disrupting a service using multiple sources of traffic.             |
| C013 | Man-in-the-Middle                    | Intercepting or potentially altering communication between parties. |
| C014 | DNS Spoofing                         | Providing misleading DNS information to redirect users.             |
| C015 | Unauthorized Network Scanning        | Probing network systems or services without permission.             |

## Account and data threats

| ID   | Threat              | Meaning                                                                        |
| ---- | ------------------- | ------------------------------------------------------------------------------ |
| C016 | Brute Force         | Repeatedly attempting passwords or credentials.                                |
| C017 | Credential Stuffing | Using previously exposed credentials to attempt account access.                |
| C018 | Account Takeover    | Gaining unauthorized control of another person's account.                      |
| C019 | Data Breach         | Unauthorized access to or disclosure of protected information.                 |
| C020 | Insider Threat      | Harmful or unauthorized activity involving someone with organizational access. |

## Application and security threats

| ID   | Threat                     | Meaning                                                         |
| ---- | -------------------------- | --------------------------------------------------------------- |
| C021 | SQL Injection              | Manipulating database queries through improperly handled input. |
| C022 | Cross-Site Scripting (XSS) | Injecting malicious scripts into content delivered to users.    |
| C023 | Broken Access Control      | Accessing resources or actions without proper authorization.    |
| C024 | Security Misconfiguration  | Unsafe or incorrect security settings.                          |
| C025 | Supply Chain Attack        | Compromising a system through a trusted supplier or component.  |
